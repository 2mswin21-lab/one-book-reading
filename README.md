# 오션중 나는 독서왕

중학교 1학년의 한 학기 한 권 읽기를 위한 반응형 웹 앱입니다. 첨부 도서 목록과 데이터표를 바탕으로 도서 20권과 퀴즈 60문항을 제공합니다. 표지는 실제 도서 표지가 아닌 자체 제작 그래픽입니다.

## 실행

```bash
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 열면 됩니다. 배포용 빌드는 `npm run build`입니다.

## 기능 및 주의사항

- 제목·작가 검색, 수준별 필터, 책 소개 및 도서별 퀴즈
- 책 한 권 선택, 독서 진도와 메모 기록. 데이터는 현재 브라우저의 localStorage에만 저장되며 브라우저 데이터 삭제 또는 기기 변경 시 사라질 수 있습니다.
- 현재 Supabase 연동, 로그인 및 기기 간 동기화는 **구현되지 않았습니다**. 독서 앱 전용 Supabase 프로젝트가 준비되면 별도로 연동해야 합니다.
- 첨부된 도서 정보와 퀴즈를 사용했습니다. 원자료는 YES24를 도서 소개 출처로 밝히고 있습니다. 공개 배포 전 콘텐츠의 저작권과 이용 권한을 확인하세요. 원본 첨부파일은 저장소에서 제외했습니다.
